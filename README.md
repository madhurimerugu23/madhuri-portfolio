# Madhuri's Portfolio

A personal portfolio website showcasing my skills, projects, academic background, and professional experience, built using React.

## Features
- Dark-themed design
- Responsive user interface
- Smooth animations
- Projects showcase
- Technical skills and experience
- Resume access
- Contact section

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3

## Getting Started

Clone the repository:

```bash
git clone https://github.com/madhurimerugu23/madhuri-portfolio.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
